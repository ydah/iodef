IODEF v2 / JSON · CBOR · XML

Exchange incident reports across three formats

Build, validate, and exchange IODEF v2 incident reports in Ruby. Work with JSON and CBOR from RFC 8727, plus supported XML structures from RFC 7970.

Get started Read the documentation

Ruby 3.3+MIT licenseRubyGems

  • Build reports

    Use typed incident and contact models with multilingual descriptions and explicit reporting identities.

  • Convert formats

    Read and write JSON, built-in CBOR, and namespace-aware XML using the same document model.

  • Locate problems

    Validate report structure with JSON Pointer diagnostics and configurable size, depth, and collection limits.

Installation

Add the gem to your Gemfile:

gem "iodef"

Run bundle install, then try the quick start. Requires Ruby 3.3 or later.

For supported dependencies and optional integrations, see the installation guide.

Scope & documentation

XML input must be UTF-8. XML Schema validation, XML Signature conversion, and ambiguous extension mappings are outside scope. Conversion preserves supported report data, not original XML formatting or signatures, and does not authenticate incident facts.

Read the full documentation for supported formats, examples, and API details.
